# Developer placeholder sounds

Synthesised, not recorded. They exist so the sound engine, groups, anti-repeat and the
soundboard can be exercised before a real library is imported, and so the automated
playback tests have something to play.

They are **not shipped content** and are not meant to sound good. Replace them by
importing real sound files through the app.

Regenerate with:

```
python3 assets/dev-sounds/generate.py
```
